# 🎓 Campus Event Finder

A modern, responsive web application that helps students discover and stay updated with campus events. Built with React, TypeScript, and Tailwind CSS — optimized for performance and accessibility.

---

## ✨ Features

- 🔍 **Event Search & Filter** – Easily browse and search for upcoming events
- 🗓️ **Categorized Listings** – Explore events by type (cultural, tech, sports, etc.)
- 🔔 **Notification Icons** – Stay updated with alerts and new events
- 🧑‍🎓 **Student Profile Support** – Customize your experience
- 🌙 **Dark Mode Friendly** – Tailored for both light and dark environments
- ⚡ **Fast Performance** – Powered by Vite and optimized builds

---

## 🛠️ Tech Stack

| Tech           | Description                                    |
|----------------|------------------------------------------------|
| **React**      | UI Library for building interactive components |
| **TypeScript** | Adds static typing for better developer tools  |
| **Vite**       | Lightning-fast build tool and dev server       |
| **Tailwind CSS**| Utility-first CSS framework for styling       |
| **Radix UI**   | Accessible primitives for custom UI components |
| **Bun**        | Modern JavaScript runtime used for package management |
